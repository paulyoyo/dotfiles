# ~/.config/kitty/salvaje-quotes.example.txt
#
# Template for ~/.config/kitty/salvaje-quotes.txt (user-local, not
# tracked in the dotfiles repo). The banner picks one line at random on
# every fresh kitty window.
#
# Format: one quote per line. `#` starts a comment; blank lines are
# skipped. Everything after a `|` is printed as a dim attribution on the
# line below, right-aligned. The attribution is optional.
#
#   quote text                          -> quote alone, no attribution
#   quote text | Author, Source          -> quote plus attribution
#
# Keep quotes under ~100 characters; longer ones are truncated with an
# ellipsis to fit the window.
